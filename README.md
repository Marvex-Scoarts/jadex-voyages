# JADEX VOYAGES

**Discover the World in Effortless Luxury** — A bespoke travel agency and luxury getaway website built from scratch with HTML, CSS, and JavaScript.

## About the Project
Jadex Voyages showcases curated international destinations, all-inclusive vacation tiers, an interactive itinerary wishlist drawer, and a VIP concierge package inquiry modal.

## Design & Aesthetic
* **Color Palette:** Mediterranean Azure Blue and Sunlit Crisp White surfaces accented with Sunlit Gold badges and borders.
* **Typography:** Pairs *Cormorant Garamond* editorial headings with clean *Plus Jakarta Sans* travel copy.

## Features
* **Iconic Destination Cards:** Interactive cards with trip duration badges, hover zoom photography, and live wishlist saving.
* **Saved Trips Itinerary Drawer:** Save dream destinations without duplicates, track the live counter in the navbar, and manage saved trips in a slide-out drawer.
* **VIP Package Inquiry Modal:** Clicking **Inquire Now** on any vacation tier opens a personalized concierge request pop-up with instant confirmation.

## Built With
* **HTML5** — Semantic travel layout
* **CSS3** — Custom variables, glassmorphism sticky header, responsive grids, and smooth hover transitions
* **Vanilla JavaScript** — Live itinerary state management and interactive modal controls
